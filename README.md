# Матрицы комплексных чисел

Практическая работа №1 по Java: класс для работы с матрицами комплексных чисел и консольный интерфейс к нему.

## Возможности

- сложение и вычитание матриц
- умножение матриц (и умножение матрицы на комплексное число)
- деление матриц: `A / B = A · B⁻¹`, если `B` квадратная и невырожденная
- транспонирование
- определитель (метод Гаусса)
- обратная матрица (метод Гаусса–Жордана)

Если операция невозможна (неподходящие размеры, вырожденная матрица), программа сообщает об ошибке и продолжает работу.
